# 煤龙拳 v2 对标设计基准

> 这份文档是 v2 的**设计规格和验收标准**。以后加功能、做美术、写测试，都先对照这里；这里没有的，先补进来再做。
> 写于 2026-11-04（Claude）。起因：前三天是"先搭框架、再按反馈一点点加"，没有先拿成熟作品做对照，导致系统、手感、美术反复返工。

## 0. 对标对象

| 角色 | 作品 | 学什么 |
|---|---|---|
| **主对标** | **KOF XIII**（2010，SNK） | 4 键系统、移动（跑/小跳/大跳/后撤）、出招表结构、帧数据、连段与气槽、高清手绘 2D 画面 |
| 打击感、清晰度 | 超级街霸 2X / 街霸 3 三度冲击 | 顿帧、受击反馈、一眼看懂的招式轮廓 |
| 简化取舍 | KOF 98 | 不做 3v3、不做 HD 槽时，系统保留到什么程度仍然好玩 |

画风目标随之确定：**高清 2D 手绘（赛璐璐）**，与现有立绘一致。

数据来源：Dream Cancel Wiki（KOF XIII Terry Bogard、EX Kyo 帧数据；KOF XIII 气槽规则），Capcom 官方专栏（顿帧），Guinness 世界纪录（Skullgirls 动画帧数）。以下"基准"列的数字都来自这些页面；没有可靠来源的写"经验值"。

## 3. 改了什么顺序

前三天是"引擎 → 填内容 → 做美术 → 按反馈加系统"，每加一个系统，动画清单就要变，美术就要跟着返工。现在改成：

1. **设计表（Claude，约半天）**：8 张角色设计表 + 系统参数表（伤害、帧数、顿帧、气槽），全部按第 1 节对齐；同时写成锁定测试。
2. **引擎补系统（Claude）**：EX 必杀、DM 两档、特殊技、帧差属性、顿帧表、训练模式工具。用占位小人就能试玩，先确认手感。
3. **冻结动画清单（光哥试玩点头后）**：特殊技、EX、两个 DM、开场、胜利姿势全部进 `requiredAnims`，帧数按第 1 节的密度来。**清单冻结后才开始批量出图**。
4. **美术**：先做 c04 定样（全部动作、256 高清、实机），过了再批量 7 人。
5. **质检**：第 1 节"验收方式"那一列就是 Q1–Q2 的规则来源，不再单独设计。

## 5. 器械角色（参考 KOF 比利·凯恩、侍魂、刀剑格斗）

成熟做法：
- **攻击距离分档**：比利的三节棍远 C/D 能覆盖约三分之一屏，代价是出招和收招都更慢、近身吃亏。器械角色的普通技**判定更长、收招更长**，近身靠少数快招自保。
- **器械也有受击判定**：棍子、拖把伸出去的部分也能被打（"打兵器"）。这是长兵器的反制手段，没有它，长兵器就无敌了。
- **兵器相撞**：两件器械的攻击判定相碰时双方弹开、火花四溅、都不吃伤害（侍魂的"拼刀"）。引擎已有 clash 事件，扩展到普通技之间。
- **刀光拖尾**：挥动器械时画一道弧形拖尾，按器械类型区分颜色和宽度。这是武器角色"华丽感"最便宜、最有效的来源。
- **每件器械一个专属性质**，而不只是"手变长了"：

| 角色 | 器械 | 距离 | 专属性质 |
|---|---|---|---|
| c07 霍兰 | 长柄大拖把、木盆 | 最长（比利型） | 泼水留下**水渍**：对手站在上面走路变慢、跑步会滑倒 |
| c05 苏红 | 铁皮大喇叭、红色横幅 | 长（横幅抽打） | 喇叭是**声波发射器**，见第 7 节 |
| c03 雷钧 | 大扳手、肩上电缆 | 中（扳手）/ 长（电缆鞭） | 扳手重击带 **1 击霸体**（硬吃一下照样打出去） |
| c02 罗铮 | 救援钩 + 救生绳 | 远（钩索） | **钩索拉拽**：远距离钩中后把对手拉到身前（可防御） |
| c06 方萤 | 双矿灯 + 充电线 | 中（灯链，流星锤型） | 灯链多段快打，适合连段 |
| c08 沈清 | 银针（暗器） | 远（投掷） | 银针命中累计**麻痹**，见第 6 节 |
| c01 林啸、c04 严正 | 无（矿灯帽只作飞行道具；检测仪、罚单本只是近身道具） | 标准 | 纯体术，和器械角色形成对比 |

## 6. 元素效果（参考 KOF 的红火/紫火、二阶堂红丸的电）

成熟做法：元素首先是**受击反应 + 特效 + 音效**（被火打中会烧黑、冒火苗，被电打中会闪出骨架），其次才是少量数值差异。持续掉血、减速之类的状态在 KOF 里很少，做多了很难平衡，所以每个元素只给**一个**系统性质：

| 元素 | 角色 | 受击表现（程序化特效，不用另画图） | 系统性质 |
|---|---|---|---|
| 火（煤火，红焰） | c01 林啸 | 受击方烧黑剪影 + 火苗、灰烬粒子 | 带火的击倒技倒地时间 +10 帧（压起身更从容） |
| 电 | c03 雷钧 | 骨架 X 光闪烁（直接用现有骨架小人画）、电弧 | 气绝值 ×1.5 |
| 声波 | c05 苏红 | 同心波纹、画面轻微扭曲、头顶冒星 | 防御硬直 +3、削血 ×1.5（压制强、破防快） |
| 蒸汽/热水 | c07 霍兰 | 白汽、水花、烫红 | 招式附带短时间的**场地物件**（蒸汽团、水渍） |
| 光 | c06 方萤 | 白闪、镜头光晕 | 飞行道具速度全游戏最快 |
| 针（穴位） | c08 沈清 | 银光点、穴位标记 | 累计 3 针 → **麻痹** 2 秒：走路变慢、不能跑 |
| 气流（高压氧） | c02 罗铮 | 气浪、尘土 | 推开/拉近（配合钩索） |
| 无 | c04 严正 | — | 改用**罚单标记**：贴上罚单后，下一次必杀命中伤害 +20% |

实现上只需要两个通用系统就能覆盖全部：
1. **场地物件**：有位置、大小、持续时间和触发效果（水渍、蒸汽团、漏电区、针阵、延迟声源）。
2. **标记计数**：挂在受击方身上，有层数和过期时间（麻痹针数、罚单）。

## 7. 飞行道具（参考 KOF：高度、体积、速度、轨迹、效果各不相同）

成熟做法：KOF 的飞行道具差异很大。有沿地面走、只能跳过去的地波（特瑞的能量波），有可以蹲下躲的高弹，有又慢又大、用来掩护前进的（雅典娜的超能力球），有抛物线、可以对空的，有放下后延迟爆发的设置型，还有能抵消几发普通弹的多段弹（EX 弹）。每个道具都能用下面这几个参数描述：

| 参数 | 可选值 |
|---|---|
| 高度 | 贴地（必须跳过）/ 中（可防御，不能蹲躲）/ 高（可蹲躲） |
| 体积 | 小 / 中 / 大（竖向大的很难跳过） |
| 速度 | 慢 / 中 / 快，轻重按键区分 |
| 轨迹 | 直线 / 抛物线 / 斜下 / 贴地 / 延迟爆发 / 原地停留 |
| 耐久 | 几次命中后消失；耐久高的能吃掉耐久低的（EX 弹打穿普通弹） |
| 存在时间 | 帧数或射程 |
| 效果 | 元素（第 6 节）、击倒、留下场地物件 |
| 数量 | 同屏最多几个（默认 1） |

本作的分配（每人风格不同，不再都是"一团光往前飞"）：

| 角色 | 道具 | 高度 / 体积 | 轨迹 / 速度 | 特点 |
|---|---|---|---|---|
| c01 林啸 | 矿灯光弹（矿灯帽） | 中 / 中 | 直线；轻慢重快 | 标准弹；EX 版带火焰，耐久 2 |
| c02 罗铮 | 救生绳 | 中 / 小 | 直线，中速，射程有限 | 命中后可追加"拉拽" |
| c02 罗铮 | 照明信号弹 | 贴地 / 小 | 贴地滑行，慢 | 下段，必须跳过；落点会燃烧片刻 |
| c05 苏红 | 喇叭声波 | 中 / 竖向大 | 直线，快，射程中等 | 难以跳过，但会随距离衰减 |
| c05 苏红 | 标语横幅 | 中 / 大 | 抛物线 | 对空用 |
| c05 苏红 | 广播回音 | — | 放置后 1 秒爆发 | 设置型，配合压制 |
| c05 苏红 | 全矿广播（DM） | 全高 / 巨大 | 直线 | 全屏声波 |
| c06 方萤 | 双灯连闪 | 中 / 小 | 直线，最快，射程短 | 2 段 |
| c07 霍兰 | 泼水 | 低 / 中 | 短抛物线 | 落地留水渍 |

## 11. 招式与连段的设计逻辑（KOF 与 SF 的共同做法）

### 11.1 普通技：速度、距离、伤害、风险此消彼长
每个普通技都有一个"职责"，参数围绕职责来定，不是统一套模板：

| 类别 | 出招 | 距离 | 伤害 | 被防后 | 职责 |
|---|---|---|---|---|---|
| 轻拳 / 轻脚 | 3–5 帧 | 短 | 低 | 不亏或小赚（0 到 +2） | 打断对手、连段起手、命中确认、压制 |
| 蹲轻脚 | 4–5 帧 | 短 | 低 | 小亏到不亏 | **下段**起手（KOF 的 蹲B 蹲B 站A） |
| 近身 C/D（KOF） | 4–5 帧 | 极短 | 中高 | 小亏 | 连段中间那一下，可取消 |
| 远距离重拳 / 重脚 | 7–12 帧 | 长 | 高 | 亏（-2 到 -8） | 中距离戳、惩罚对手打空的招 |
| 蹲重脚 | 8–10 帧 | 长 | 中 | 大亏 | 下段倒地（扫腿） |
| 对空普通技 | 5–7 帧 | 向上 | 中 | 亏 | 打对手跳入 |
| 特殊技（6A 之类） | 慢 | 中 | 中 | 小亏 | 中段，或者用来接连段 |

关键规则：
- **手脚伸出去的部分也能被打**（受击判定跟着手脚走）。这样"出招长"才有代价：打空了，对方可以打你伸出来的腿。KOF 和 SF 的"立回"（中距离互相试探）都建立在这一点上。
- 轻攻击快在"出招"和"收招"两头，重攻击慢在两头。玩家感觉到的"快慢"主要是收招，不只是出招。

### 11.2 每个人的手脚长度和出招速度要不同（现在没做到）

### 11.3 必杀技
- **三角关系**：飞行道具管远距离，升龙类对空管跳入，突进技管近距离。主角型（林啸）三样都有，其他人缺一两样，靠缺的那样形成打法差异和弱点。
- **指令难度与回报对应**：236 最容易，给常规招；623 更难，给带无敌的对空；双重指令给超必杀。
- **轻 / 重 / EX 三版**：轻版快、短、被防后较安全；重版远、伤害高、被防后亏很多；EX 版花 1 气，带无敌或多段、更安全。
- **被防后是否安全**是必杀的核心参数：安全的突进技能用来压制，不安全的只能在连段里用。

### 11.4 连段的两种做法
- **SF：连接（link）+ 取消（cancel）。**
  - 连接：前一招命中后自己先恢复，空出的帧数 ≥ 下一招的出招帧，就能接上，要求按键时机准。例子：Ibuki 的站中拳命中后 +6，可以再接一个站中拳。SFV 起把连接的输入窗口放宽，降低门槛。
  - 取消：在命中瞬间直接用必杀或超必杀接掉后续动作，不讲时机。
  - 层级：普通技 → 必杀 → 超必杀。
- **KOF：以取消为主，连接很少。**
  - 典型路线一：跳 C → 近 C → 特殊技 → 必杀 →（超必杀取消）超必杀。
  - 典型路线二：从下段起手，蹲B 蹲B 站A（轻攻击连打）→ 必杀。
  - 轻攻击之间可以连打（类似罪恶装备的连招系统）。
  - 小跳攻击可以当快速中段起手。
  - 反击命中时，本来会击倒的招变成可以追打（浮空追击）。
- **共同的结构**：
  - **起手**：快招、下段、中段、跳入、反击命中。
  - **确认**：前一两下命中了才继续，没命中就停下保持安全。
  - **中段**：可取消的重攻击或特殊技。
  - **收尾**：必杀，决定对手是软倒地还是硬倒地，硬倒地才方便压起身。
  - **资源延伸**：花气接超必杀。
- **伤害规则**：轻攻击起手的连段伤害低，重攻击、跳入、反击起手的伤害高；伤害按击数递减，防止无限连；每用 1 气大约多 10% 伤害。

### 11.5 整局的循环（之前缺的就是后半段）
立回（中距离试探）→ 命中 → 连段 → 击倒 → **压起身**（中/下段、投、诈帧二选一）→ 防守方的应对（无敌技、防御反击、翻滚、受身、拆投）→ 回到立回。
现在引擎有前半段，但"击倒后怎么打"和"防守方怎么脱身"都不完整，所以打起来平、没有攻防来回。这一条比加元素、加道具优先。
