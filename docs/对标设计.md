# 煤龙拳 v2 对标设计基准

> 这份文档是 v2 的**设计规格和验收标准**。以后加功能、做美术、写测试，都先对照这里；这里没有的，先补进来再做。
> 写于 2026-11-04（Claude）。起因：前三天是"先搭框架、再按反馈一点点加"，没有先拿成熟作品做对照，导致系统、手感、美术反复返工。

## 0. 对标对象

| 角色 | 作品 | 学什么 |
|---|---|---|
| **主对标** | **KOF XIII**（2010，SNK） | 4 键系统、移动（跑/小跳/大跳/后撤）、出招表结构、帧数据、连段与气槽、高清手绘 2D 画面 |
| 打击感、清晰度 | 超级街霸 2X / 街霸 3 三度冲击 | 顿帧、受击反馈、一眼看懂的招式轮廓 |
| 简化取舍 | KOF 98 | 不做 3v3、不做 HD 槽时，系统保留到什么程度仍然好玩 |

画风目标随之确定：**高清 2D 手绘（赛璐璐）**，与现有立绘一致。

数据来源：Dream Cancel Wiki（KOF XIII Terry Bogard、EX Kyo 帧数据；KOF XIII 气槽规则），Capcom 官方专栏（顿帧），Guinness 世界纪录（Skullgirls 动画帧数）。以下"基准"列的数字都来自这些页面；没有可靠来源的写"经验值"。

## 1. 差距总表

| 维度 | 基准（KOF XIII 等） | 我们现在 | 目标 | 验收方式 |
|---|---|---|---|---|
| 体力与伤害 | 体力 1000；轻攻击 25–30，重攻击 70–80，必杀 60–120，DM 180–210，EX DM 300–360，NEOMAX 450 | 体力 980–1150；重攻击 88–106（偏高约 20%）；超必杀一档 200–350 | 按基准重标伤害；超必杀分 DM / MAX 两档 | 锁定测试：每类招式伤害落在区间内 |
| 普通技帧数 | 站 A 4/3/8；站 C 7/6/19；近 C 4/6/18；蹲 B 4/4/10（下段）；蹲 D 10/5/29（下段，倒地） | 数值接近，但 8 人是同一模板加减 1–2 帧，受击硬直全员一样 | 每人普通技按角色定位区分（判定范围、发生、属性） | 锁定测试：区间 + "8 人普通技不能全同" |
| 招式属性 | 每招标注：上/中/下段、可取消等级、软/硬倒地、命中/防御帧差 | 只有 level 和 knockdown，没有帧差设计 | 每招写明命中/防御帧差和取消等级，出招表显示 | 测试：所有普通技有帧差字段，轻攻击防御后不吃亏 |
| 出招表规模 | 每人约 2 个特殊技（6A、3C 之类）、4–6 个必杀（轻/重/EX 三版）、2–4 个 DM（含 EX）、1 个 NEOMAX | 4 个必杀（其中 1 个其实是特殊技）、1 个超必杀，没有 EX | 每人 2 个特殊技、4 个必杀（含 EX 版）、2 个 DM、1 个 MAX 超必杀 | 锁定测试：结构完整 |
| 角色定位 | 每人有明确打法（压制 / 远程 / 投技 / 均衡）和工具：对空、下段、中段、无敌技、飞行道具或突进 | 有 archetype 字段，但工具没核对 | 每人一张"打法卡"：定位 + 工具清单 + 弱点 | 测试：工具清单齐全（对空、下段、中段、无敌技必有） |
| 基础连段 | 0 气约 20–32%（如 跳C → 近C → 必杀 → 追加）；1 气约 30–40%；满资源约 60% | 只验证过能连，没有测伤害 | 每人写 3 条基础连段：0 气 / 1 气 / 满资源 | 无头测试：每条连段都能打出，伤害落在区间内 |
| 气槽 | 1 气 = EX 必杀 / DM；2 气 = EX DM；超必杀取消要额外消耗 | KOF97 爆气 + MAX；超必杀取消已有 | 保留 97 爆气，补上 EX 必杀（1 气）和 EX DM（2 气） | 引擎测试 |
| 移动 | 小跳约 4+25 帧，普通跳约 4+35 帧，后撤约 18+3 帧 | 跳约 32 帧，小跳约 22 帧，后撤 16 帧（基本对齐） | 不动 | 已有测试 |
| 打击感：顿帧 | 街霸 2 约 10 帧；Capcom 专栏举例 轻/中/重 = 8/12/16 | 6/8/10，超必杀 14，偏短 | 8/11/14，超必杀 18，反击 +4；多段攻击每段减半 | 引擎测试 + 试玩 |
| 打击感：其他 | 受击方抖动、按力度分级的火花、分层音效、超必杀暗场 | 都有 | 按力度分 3 档调参，对照基准录屏 | 并排对比录屏 |
| 动画密度 | Skullgirls 平均 1,439 帧/人；手绘格斗游戏一张图约顶 2–3 个游戏帧（经验值） | 约 190 帧/人，一张图顶约 5 个游戏帧，动作发卡 | 约 500–700 帧/人：普通技 6–12 张，必杀 12–20 张，待机和走路各 10 张 | 图集测试：每类动画的最少帧数 |
| 角色尺寸 | 高清 2D，角色约占画面高度的 40%（经验值） | 逻辑 90px / 224px 约 40%，128 像素帧，放大后发糊 | 256 像素帧（V2-2） | 已有 V2 测试 |
| 演出 | 每人有开场、胜利姿势，宿敌之间有专属开场对白 | 故事模式有对白，没有开场和胜利动画 | 每人 1 个开场 + 2 个胜利姿势（进动画清单） | 图集测试 |
| 模式 | 街机/故事、对战、训练（帧数据显示、判定框、录制假人、输入显示、连段挑战） | 故事、对战、基础训练 | 训练模式补齐：帧差显示、录制回放假人、每人 3 条连段挑战 | e2e 测试 |
| 平衡 | 职业赛有经验值 | 有平衡矩阵（胜率 20–80%） | 保留，加"单招伤害占比 ≤50%" | 已有 + Q2 |

## 3. 改了什么顺序

前三天是"引擎 → 填内容 → 做美术 → 按反馈加系统"，每加一个系统，动画清单就要变，美术就要跟着返工。现在改成：

1. **设计表（Claude，约半天）**：8 张角色设计表 + 系统参数表（伤害、帧数、顿帧、气槽），全部按第 1 节对齐；同时写成锁定测试。
2. **引擎补系统（Claude）**：EX 必杀、DM 两档、特殊技、帧差属性、顿帧表、训练模式工具。用占位小人就能试玩，先确认手感。
3. **冻结动画清单（光哥试玩点头后）**：特殊技、EX、两个 DM、开场、胜利姿势全部进 `requiredAnims`，帧数按第 1 节的密度来。**清单冻结后才开始批量出图**。
4. **美术**：先做 c04 定样（全部动作、256 高清、实机），过了再批量 7 人。
5. **质检**：第 1 节"验收方式"那一列就是 Q1–Q2 的规则来源，不再单独设计。
