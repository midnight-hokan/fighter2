# 角色数据格式

一个角色 = `src/theme/<主题>/characters/cNN.js` 里导出的一个普通对象。引擎只读数据，不需要为角色写任何代码。
完整示例：`src/theme/meilong/characters/c01.js`。校验器：`src/engine/validate.js`（R1 测试会对每个角色跑一遍）。

坐标约定：像素，场景原生分辨率 384×224，地面 y=200。判定框 `{x, y, w, h}` 相对角色脚底中心，**x 朝前为正、y 朝上为正**（y 是框的下沿离地高度）。时间单位都是帧（60 帧 = 1 秒）。

## 基本信息

| 字段 | 说明 |
|---|---|
| `id` | 唯一 id，如 `c03` |
| `name` / `title` | 名字 / 称号（中文，原创，不能用街霸、拳皇角色名） |
| `style` | 外观描述（给美术生成用的提示词底稿） |
| `archetype` | `shoto` 波升型 / `charge` 蓄力型 / `grappler` 投技型 / `rushdown` 压制型 / `zoner` 远程型 / `speed` 速度型 / `power` 力量型 / `balanced` 均衡型 |
| `colors` | `primary`（必填，8 人互不相同）、`secondary`、`skin` |
| `ending` | 街机模式通关结局文字，≥30 字 |
| `stage` | 主场场景 id（R2 起必填），对战时用对手的主场 |
| `stats` | `health` 800–1200，`walkF` 1.2–4.5，`walkB` 1–4，`jumpV` 6.5–11，`jumpH` 1.8–5，`stunMax` 70–160，`throwRange` 30–70 |

## 普通技 `normals`

必须 18 个：`st.lp st.mp st.hp st.lk st.mk st.hk`、`cr.*`、`j.*`。每个招式字段：

| 字段 | 说明 |
|---|---|
| `name` | 招式名 |
| `startup` / `active` / `recovery` | 发生 / 持续 / 收招帧 |
| `damage` / `stun` | 伤害 / 气绝值 |
| `hitstun` / `blockstun` | 命中硬直 / 防御硬直 |
| `hitbox` | 攻击判定框 |
| `level` | `'mid'` 站蹲都能防、`'low'` 下段（必须蹲防）、`'high'` 中段（必须站防）。默认：`j.*` 为 high，`cr.*k` 为 low，其余 mid |
| `cancel` | 命中/被防后可取消成必杀技/超必杀 |
| `knockdown` | 命中后击倒 |
| `pushback` / `hitstop` / `meterGain` / `chip` | 可选覆盖 |
| `anim` | 占位火柴人动作：`punch heavy upper kick highkick lowkick sweep fireball uppercut spin super throw grab rush` |

## 投技 `throw`

`{ name, damage, stun }`。输入：靠近对手时 `6/4 + 重拳或重脚`。

## 必杀技 `specials`（≥3）与超必杀 `supers`（≥1）

在普通技字段基础上增加：

| 字段 | 说明 |
|---|---|
| `id` | 招式 id（动画名也用它） |
| `input` | 数字键盘记法，见下 |
| `desc` | 出招表说明 |
| `projectile` | 飞行道具 `{ speed, x, y, w, h, life }`，每人同时只能有一个 |
| `move` | 招式位移 `{ vx, vy, at, frames }`：第 `at` 帧开始，水平速度 vx 持续 frames 帧；vy>0 起跳 |
| `invuln` | 无敌帧区间 `[起, 止]` |
| `throw: true, range` | 指令投（打不中防御中的对手，按 range 判定距离） |
| `air: true` | 空中也能出 |
| `strength` | 轻/重版本差异：`{ l: {...覆盖字段}, h: {...} }`，中版用基础值 |
| `sdm` | 仅超必杀：MAX 状态下发动时的覆盖字段（如更高伤害、更长无敌） |

超必杀要求：指令至少 6 个方向（如 `236236P`），伤害 ≥200。

## 指令写法

数字键盘记法（面向右时）：`1↙ 2↓ 3↘ 4← 5中 6→ 7↖ 8↑ 9↗`，面向左时引擎自动镜像。

- 搓招：`236P`（下前拳）、`623P`（升龙）、`214K`、`41236HP`（只认重拳）
- 蓄力：`[4]6P` 后蓄约 0.7 秒再前+拳；`[2]8K` 下蓄后上+脚
- 一圈：`360P`
- 按键：`P`=任意拳、`K`=任意脚，或 `LP MP HP LK MK HK` 指定

同一角色的指令不能重复；不同角色之间招式输入组合要有区别（R1 测试会检查）。

## 通用系统（KOF97 ADVANCED，所有角色共有，不用写在数据里）

- 气槽：攻击/被打都会攒气，满一格得一颗能量珠，最多 3 颗，跨回合保留
- 超必杀（DM）：消耗 1 颗
- 爆气 MAX：LP+MP+HP，消耗 1 颗，约 8 秒内攻击力 ×1.25；MAX 中再发超必杀 = MAX 超必杀（SDM），再多耗 1 颗
- 紧急回避：LP+LK，前段无敌
- 防御反击：防御硬直中 LP+LK（回避反击）或 HP+HK（吹飞反击），各耗 1 颗
