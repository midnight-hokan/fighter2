# 煤龙拳 v2 角色设计表（8 人）

> 按 `docs/对标设计.md` 写成。先定表，再改数据和引擎，最后冻结动画清单交给美术。
> 按键：A 轻拳、B 轻脚、C 重拳、D 重脚；P = A 或 C，K = B 或 D。方向用小键盘数字（6 = 前，2 = 下，236 = 下前前）。
> 方括号里是现有招式 id。保留 id 就能沿用已经做好的动画；标"新"的是新增招式，需要补动画。
> 伤害区间（体力按 1000 计）：轻攻击 25–30｜重攻击 70–80｜必杀 60–120｜DM 180–210｜EX DM 300–360｜极限超必杀 约 450。
> 连段伤害目标：0 气 20–28%｜1 气 30–40%｜满资源 55–60%。
> 每人都要有：对空手段（带无敌）、下段、中段、至少一条 0 气连段。

## c01 林啸｜采煤队长｜均衡型（对标草薙京 / 特瑞）
- **元素**：火（煤火，红焰）　**器械**：无，矿灯帽只当飞行道具
- **打法**：中距离用光弹牵制，对手跳过来就用 623P 对空；近身从蹲 B 起手打连段。标准主角，什么都会一点。
- **弱点**：中段只有 6A，压起身的择不多。
- **特殊技**：6A 灯压 [dengya]（中段）｜新 3C 截割上挑（对空，可取消成必杀）
- **必杀**
  - 236P 矿灯光弹 [meiyan]：标准中速弹，A 慢 C 快；EX 版带火，耐久 2
  - 623P 液压支架顶 [chongtian]：对空，1–8 帧无敌，带火；EX 版全程无敌
  - 214K 滚筒旋踢 [xuanfeng]：突进，可从飞行道具下面穿过
  - 新 41236P 煤火掌：近身火掌，命中后可追加 P 第二段
- **DM**：236236P 全速截割 [dihuolong]（突进，带火）｜新 214214P 地火喷涌（地面火柱，对空、远距离）
- **极限超必杀**：新 2363214C **煤龙拳**（游戏标题招，火龙贯穿）
- **连段**
  - 0 气：蹲B 蹲B 站A > 214B（约 20%）
  - 0 气：跳C 近C 3C > 623C（约 28%）
  - 1 气：跳C 近C 6A > 623A >（超必杀取消）236236P（约 38%）
  - 满资源：跳C 近C 3C > 623(EX) >（超必杀取消）煤龙拳（约 58%）

## c02 罗铮｜矿山救护队员｜蓄力型（对标古烈 / 拉尔夫）
- **元素**：气流（高压氧）　**器械**：救援钩 + 救生绳（远距离锁链型）

- **弱点**：蓄力限制了进攻，前冲慢，被贴身压制时只能靠对空和防御反击。
- **特殊技**：3D 钩扫 [gousao]（下段，倒地）｜新 6C 氧气瓶撞（中段）
- **必杀**

  - [2]8K 救援钩上挑 [chongtianshan]：对空，1–10 帧无敌
  - 新 [2]8P 钩索拉拽：远距离打击投（可防御），钩中后把对手拉到身前，可接连段
- **DM**：[4]646P 生命通道 [longxuantan]（突进；原指令 236236P 改为蓄力超必杀的标准写法）｜新 [4]646K 氧气爆喷（近身气浪，吹飞）
- **极限超必杀**：新 [2]8 2 8C 绝境救援（钩索拉入 + 连打）
- **连段**
  - 0 气：蹲B 蹲A 站A > [4]6A（约 18%，需先蓄力）
  - 0 气：钩索拉拽命中 > 近C 6C > [2]8D（约 27%）
  - 1 气：跳C 近C > [2]8B >（超必杀取消）[4]646P（约 36%）

## c03 雷钧｜机电队长｜投技型（对标大门五郎 / 克拉克）

- **DM**：632146P 高压送电 [chaozhong]（大投，带电；原指令 236236K 改为投技超必杀的标准写法）｜新 236236K 漏电区（地面电场持续 4 秒，对手踩上就触电）
- **极限超必杀**：新 2 圈指令 + C **全矿停电**（大投，黑屏后电光）

## 统计

- 每人：2 个特殊技、4 个必杀（各有轻、重、EX 三版）、2 个 DM（各有 EX 版）、1 个极限超必杀。
- 新增招式共 32 个（每人 4 个），都要补动画；开场和 2 个胜利姿势另算。
- 元素受击、刀光、飞行道具、场地物件都用程序化特效，不需要画图。
- 指令改动：c02 生命通道 → [4]646P；c03 高压送电 → 632146P，缆鞭扫 → 214K；c07 拖把直戳 → 6C。
