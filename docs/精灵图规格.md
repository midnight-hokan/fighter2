# 精灵图规格（美术接入）

没有精灵图的角色会自动用程序化火柴人占位，所以美术可以一个角色一个角色地替换，随时可玩。

## 目录

```
public/assets/manifest.json
public/assets/<主题id>/<角色id>/atlas.json
public/assets/<主题id>/<角色id>/atlas.png
```

manifest.json：`{ "meilong": { "c01": "assets/meilong/c01/atlas.json" } }`

## atlas.json

```json
{
  "image": "atlas.png",
  "frameW": 128, "frameH": 128, "columns": 8,
  "anchor": { "x": 64, "y": 124 },
  "animations": {
    "idle": { "frames": [0, 1, 2, 3], "fps": 8, "loop": true },
    "st.lp": { "frames": [8, 9, 10], "fps": 20 }
  }
}
```

- 所有帧大小一致，从左到右、从上到下排成网格；帧序号从 0 开始
- `anchor` = 单帧里**脚底中心**的位置，引擎把它对齐到角色坐标
- 朝右画；朝左由引擎水平翻转
- 尺寸参考：角色身高约 90 像素（场景原生 384×224，整数倍放大显示），frameW/H 在 48–256
- 背景透明 PNG，像素风建议关掉抗锯齿
- 攻击动画的帧会按招式总帧数等比铺开，不需要和帧数据一一对应

## 必须有的动画

状态：`idle walkf walkb crouch prejump jump blockstun crblock hitstun airhit knockdown dizzy roll maxstart ko win throw gc`
招式：18 个普通技 id（`st.lp` … `j.hk`）+ 每个必杀技 id + 每个超必杀 id。

缺任何一个，浏览器控制台会打印校验错误，并且该角色继续用占位火柴人（不会崩）。

## 本地模型生成建议流程

1. 用角色数据里的 `style` 字段做提示词底稿，先出一张定稿立绘，固定配色（`colors`）
2. 用同一角色参考图（IP-Adapter / 角色 LoRA）逐个生成动作关键帧，统一侧视、朝右、同一比例
3. 抠图 → 缩放到统一身高 → 按网格拼成 atlas.png（可写个小脚本）
4. 写 atlas.json，刷新页面即可看到；F1 显示判定框，对照调整 anchor
