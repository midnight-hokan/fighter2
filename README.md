# 煤龙拳 v2

2D 像素格斗游戏，玩法参照超级街霸2X，气槽系统参照拳皇97 ADVANCED（KOF97）。纯网页实现，浏览器直接玩，无需安装。

故事背景：黑岭煤矿建矿六十周年，矿上恢复"地下擂台"的老传统——赢下全部七场，捧走全矿唯一一盏头灯。

- 8 名原创黑岭煤矿角色，两两平衡（36%–71% 全落在 20–80% 健康区间）
- 6 个矿镇场景，各带专属配色、3 层视差背景与独立 BGM
- 故事模式（原街机模式）：每个角色一条独立故事线，按剧本顺序挑战 7 名对手，每战有专门的对战前对话，第三战后有中段剧情，通关播放角色结局
- 对战模式（对电脑 普通/困难/简单、本地双人）
- 训练模式

## 运行

```bash
npm ci
npm run dev          # 开发服务器
npm run check        # 全部自检（E1–E8 引擎、R1–R4 内容）
npm run shot         # 对战截图
npm run deploy       # 发布到网站（需要 DEPLOY_TARGET / SITE_URL）
```

调试：地址后加 `?test=1` 进入测试模式（暴露 `window.__game` 接口）。

## 操作键位（拳皇式 4 键：A 轻拳 · B 轻脚 · C 重拳 · D 重脚）

**P1（键盘）**
- 移动：`W` `A` `S` `D`
- A 轻拳 `J` · B 轻脚 `K` · C 重拳 `U` · D 重脚 `I`

**P2（键盘）**
- 移动：`方向键`（↑ ↓ ← →）
- A 轻拳 `小键盘` `1` · B 轻脚 `2` · C 重拳 `4` · D 重脚 `5`

**手柄**（标准布局，P1/P2 各一个）
- 移动：十字键 / 左摇杆
- A 轻拳 `X` · B 轻脚 `A` · C 重拳 `Y` · D 重脚 `B`
- `Start` 用于菜单确认

**手机**：左侧摇杆移动，右侧 A B C D 四键，另有"必杀"键一键出必杀。

> 键位以 `src/ui/controls.js` 为准；改动键位时本文与出招表说明需同步。

## 通用系统

- **气槽（KOF97 进阶）**：最多 3 格，每格 100。出拳/必杀/投技/受击都会涨气（被防御时减半），用来放超必杀和爆气。
- **爆气**：气 ≥ 1 格时同时按 A+B+C，进入 MAX 状态 8 秒，期间伤害 ×1.25。
- **近身/远距离重攻击**：贴身按 C 或 D 出近身版（发生快、可取消接必杀）；离远了是远距离版（打得远、不能取消）。
- **脚比手长**：脚类普通技判定更远，适合牵制；拳类出手快、可取消，适合接连段。
- **连段**：A、B 轻攻击可互相连打（最多 2 次）；可取消的普通技命中后输入必杀/超必杀。标准连招：跳 D → 近 C → 必杀，或 蹲 B → 蹲 A → 必杀。
- **小跳 / 大跳**：点一下"上"（马上松开）是小跳，又低又快，用来突进；按住"上"是普通跳；先按"下"再马上按"上"是大跳，又高又远。
- **跑步 / 后撤步**：快速双击"前"并按住是跑步，跑动中起跳更远；快速双击"后"是后撤步，开头几帧无敌。
- **超必杀取消**：必杀技打中后马上输入超必杀指令，直接接超必杀，共消耗 2 豆。
- **CD 吹飞攻击**：同时按 C+D，发生稍慢、判定远，命中把对手打倒；空中也能用。
- **反击**：在对手出招的瞬间打中他，硬直更长，更好追击。
- **超必杀 / MAX 超必杀**：气 ≥ 1 格 + 对应指令出招；在爆气状态下打出即为 **MAX 超必杀**，伤害再 ×1.6（招式可单独指定）。
- **紧急回避**：同时按 A+B（轻拳+轻脚），26 帧翻滚，1–16 帧无敌，用来躲飞行道具。
- **防御反击**：被压到防御硬直时，气 ≥ 1 格，同时按轻拳+轻脚=防御回避翻滚，同时按重拳+重脚=防御反击打飞。
- **投技**：近身时 前/后 + 重拳或重脚。
- **出招表**：对战中按 `Esc` 随时查看双方所有必杀技与超必杀。

调试快捷键：`F1` 判定框 · `F2` 训练假人 · `M` 静音 · `Esc` 出招表。

## 故事

黑岭煤矿建矿六十周年，矿上恢复"地下擂台"的老传统：八名职工各自报名，为各自想要的东西而战。完整身份、参赛缘由与通关结局见 `docs/故事设定.md`。

## 模式

- **故事模式（街机模式）**：选角后先播放该角色的开场白与参赛缘由；前六战按该角色的剧本顺序（宿敌放在后面），**第七战固定为沈清**（若玩家选沈清，第七战为林啸），难度从 easy 到 hard 逐战变难；第三战后插入中段剧情。每战横幅显示对手姓名与身份，输了可接关 3 次（对手不变），赢满 7 场播放该角色结局。
- **训练模式**：无限时间、可重置假人，`F2` 切换假人行为，`F1` 看判定框。
- **双人对战**：P1 + P2 同键盘或双柄。
- **单人挑战**：P1 对战电脑，难度三档。
